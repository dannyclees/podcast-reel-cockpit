# What the app reads from the brand

For `setup/build_brand.py`. These names are exact. The app has no brand of its own, so anything left out here shows as missing.

## public/brand.css

Add this block to `:root`, from `app_colors` in brand.json. The app reads these and nothing else for its colours.

| Token | From |
|---|---|
| `--app-bg` | `app_colors.bg` |
| `--app-bg-2` | `app_colors.bg_2` |
| `--app-surface` | `app_colors.surface` |
| `--app-line` | `app_colors.line` |
| `--app-line-2` | `app_colors.line_2` |
| `--app-ink` | `app_colors.ink` |
| `--app-ink-2` | `app_colors.ink_2` |
| `--app-mute` | `app_colors.mute` |
| `--app-accent` | `app_colors.accent` |
| `--app-accent-soft` | `app_colors.accent_soft` |
| `--app-accent-ink` | `app_colors.accent_ink` |

The app also reads these render tokens from the contract: `--font-display`, `--font-body`, `--font-mono`, `--on-accent`.

Two optional tokens:

| Token | What it does | If left out |
|---|---|---|
| `--app-font-body` | The family for the app's body text, from `fonts.app_body`. | Falls back to `--font-body`. |
| `--app-on-accent` | Text on a solid accent fill, if `app_colors.accent` differs from `colors.accent`. | Falls back to `--on-accent`. |

Important: the app's body text uses weights 400, 500 and 600. The contract loads `BrandBody` at 700 and 800 only, so with no `--app-font-body` all small text shows bold. Please also write a regular weight of `fonts.app_body` to `public/fonts/app-body.ttf`, with an `@font-face` rule covering weight 400 to 600, and set `--app-font-body` to that family.

Font paths in the app's copy of brand.css must work from the site root: `/fonts/...` or `fonts/...` both work, since brand.css is served from `/`.

## public/brand.js

`window.BRAND = {...}`. The same shape as brand.json. These are the only keys the page reads:

- `show.name`
- `app.title`, `app.approver`
- `posting.always_tags`, `posting.cta_line`, `posting.timezone`
- `music`: each entry is a string or `{name}`, used as the track label. Empty means Track 1, Track 2, Track 3.
- `shorts_per_episode`

Never put keys, passwords or the service key in this file. The browser can read it.

## api/_brand.js

`export default {...}`. The same shape as brand.json. These are the only keys the server reads:

- `app.bucket`
- `posting.timezone`, `posting.gap_hours`, `posting.clash_hours`
- `posting.youtube_channel_id`: blank skips the full-episode lookup.
- `posting.instagram_username`: blank leaves Instagram numbers off.
- `posting.youtube_category_id`: optional, not in the example file. Blank means `22`.

`posting.tiktok_username` is not read. TikTok numbers come from each post's own link.

## Files the page loads

- `public/brand.css`, `public/brand.js`
- `public/img/logo.png`: shown on the ink band of the masthead. If missing, the logo is left out.
- `public/img/band.jpg`: the texture on the masthead, the Views tile and other ink bands.
- `public/img/edge.jpg`: generated by the contract. The current CSS does not use it.
- `public/fonts/`
